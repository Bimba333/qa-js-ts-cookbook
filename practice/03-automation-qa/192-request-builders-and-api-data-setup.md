## Задача 1. Концептуальные вопросы

Зачем Request Builder нужны валидные значения по умолчанию, переопределения для конкретного сценария и независимый результат `build()`?

## Задача 2. Анализ данных

Builder возвращает ссылку на один и тот же изменяемый объект. Два теста меняют `title`. Опишите риск и исправьте контракт `build()`.

## Задача 3. Предскажите результат

Очистка выполняется только после проверки. Что произойдёт с серверным ресурсом при раннем падении теста?

## Задача 4. Поиск ошибки

Метод `build()` сам отправляет POST и сохраняет ID внутри singleton. Разделите построение тела данных, API-вызов и владение очисткой.

## Задача 5. Automation QA

Предложите стратегию уникальных данных для повторных запусков и объясните, почему при очистке следует использовать ID ответа, а не `title`.

## Задача 6. Мини-проект
