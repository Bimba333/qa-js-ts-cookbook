## Задача 1. Концептуальные вопросы

Объясните разницу между объявлением теста, обнаружением и выполнением тела в worker.

## Задача 2. Чтение кода

Найдите название, тело теста, built-in fixture, действие и проверку:

```ts
test("открывает отчёт", async ({ page }) => {
  await page.setContent("<button>Открыть</button>");
  await page.getByRole("button").click();
  await expect(page.getByRole("button")).toBeVisible();
});
```

## Задача 4. Debugging

Исправьте пропущенный `await`:

```ts
page.getByRole("button", { name: "Сохранить" }).click();
await expect(page.getByText("Сохранено")).toBeVisible();
```

Объясните риск исходного кода.
