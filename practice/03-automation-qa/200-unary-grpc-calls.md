# Практика: Unary gRPC-вызовы

## Задача 1. Концептуальные вопросы

Каков жизненный цикл unary call? Чем он отличается от времени жизни channel?

## Задача 2. Анализ обёртки Promise

Обёртка вызывает `resolve(response)` даже при наличии `error`. Найдите ложноположительный путь и задайте корректные ветви завершения.

## Задача 3. Предскажите результат

Тест запускает RPC с callback, не возвращает Promise и сразу завершается. Что произойдёт с проверкой внутри callback?

## Задача 4. Поиск ошибки

После вызова используется `waitForTimeout(500)` вместо ожидания callback. Замените временную догадку на сигнал завершения.

## Задача 5. Automation QA

Спроектируйте последовательность unary create/get с явными request, response, ошибкой и освобождением ресурсов.

## Задача 6. Мини-проект

Напишите обобщённый адаптер Promise для unary call, который не теряет `ServiceError` и отклоняется при отсутствии response.
