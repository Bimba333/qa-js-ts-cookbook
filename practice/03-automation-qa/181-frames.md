# Практика: Frames

## Задача 1. Концептуальные вопросы

Чем `Frame` отличается от `FrameLocator`? Почему основной `page` не ищет элементы внутри iframe автоматически?

## Задача 2. Анализ контекста

Платёжная кнопка находится внутри iframe, а статус заказа — в основной странице. Укажите правильную границу Locator для каждого элемента.

## Задача 3. Предскажите результат

Тест использует `page.getByRole("button", { name: "Оплатить" })`, но кнопка существует только внутри iframe. Что произойдёт при `click()`?

## Задача 4. Поиск ошибки

Тест выбирает `page.frames()[1]` и иногда работает с рекламным frame вместо формы. Найдите нестабильный способ выбора и предложите устойчивый поиск.

## Задача 5. Automation QA

Опишите проверку встроенного отчёта: как выбрать iframe, дождаться заголовка внутри и отдельно проверить статус загрузки основной страницы без фиксированной задержки.

## Задача 6. Мини-проект

Создайте локальную страницу с iframe через `srcdoc`, заполните поле и нажмите кнопку внутри через `FrameLocator`, затем проверьте изменение атрибута внутри frame.
