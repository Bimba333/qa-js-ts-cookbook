# Практика: Component Objects и композиция страниц

## Задача 1. Концептуальные вопросы

Что отличает Component Object от Page Object? Зачем компоненту корневой Locator и почему композиция не требует общего базового класса?

## Задача 2. Анализ границы

На странице две таблицы с кнопкой «Обновить». Как корневой Locator позволяет создать два экземпляра одного `TableComponent` без глобального селектора?

## Задача 3. Предскажите результат

Компонент вызывает `root.getByRole("button", { name: "Удалить" })`, а такая кнопка есть только вне корневого Locator. Найдёт ли её Locator?

## Задача 4. Поиск ошибки

Каждая подпись и иконка вынесена в отдельный класс. Объясните, почему такая декомпозиция ухудшает поддержку, и сформулируйте критерий осмысленного компонента.

## Задача 5. Automation QA

Спроектируйте `HeaderComponent` и `DashboardPage`, где заголовок используется через композицию. Разделите их публичные действия и владение Locators.

## Задача 6. Мини-проект

Реализуйте `NotificationComponent` с корневым Locator, методом `dismiss()` и Locator текста. Используйте два экземпляра компонента в `SettingsPage` и проверьте закрытие только выбранного уведомления.
