# Практика: Аутентификация API

## Задача 1. Концептуальные вопросы

Разведите аутентификацию и авторизацию. Чем API key отличается от bearer token на уровне тестового запроса?

## Задача 2. Анализ доступа

Запрос без token получает 401, а запрос с token роли QA к административному маршруту — 403. Объясните разницу причин.

## Задача 3. Предскажите результат

Набор тестов использует один token, срок которого истекает через минуту. Какие типы нестабильности возможны и почему новый APIRequestContext не обновит token сам?

## Задача 4. Поиск ошибки

Реальный административный token записан в код и выводится при падении. Опишите безопасную границу хранения секретов и диагностические ограничения.

## Задача 5. Automation QA

Составьте позитивный сценарий минимальной роли и два негативных сценария: отсутствующие учётные данные и недостаточные разрешения.

## Задача 6. Мини-проект

На локальном API получите тестовый token через `/sessions`, передайте заголовок bearer в `/profile` и отдельно проверьте 401 и 403 без логирования token.
