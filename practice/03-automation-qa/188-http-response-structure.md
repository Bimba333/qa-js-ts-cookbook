# Практика: Структура HTTP-ответа

## Задача 1. Концептуальные вопросы

Объясните роли кода состояния, заголовков и тела ответа. Чем транспортная ошибка отличается от ошибки приложения, переданной в HTTP-ответе?

## Задача 2. Анализ ответа

API вернул 201, `Location: /tasks/task-8` и JSON созданной задачи. Какие проверки относятся к HTTP-контракту, а какие — к бизнес-данным?

## Задача 3. Предскажите результат

Маршрут возвращает 204 без тела. Что произойдёт с попыткой прочитать JSON и какую проверку следует выполнить вместо этого?

## Задача 4. Поиск ошибки

Тест принимает любой результат `response.ok()` для асинхронного запуска, хотя контракт требует 202 и `jobId`. Найдите возможность ложноположительного результата и уточните проверки.

## Задача 5. Automation QA

Сравните значения 200, 201, 202 и 204 для четырёх практических API-сценариев. Не превращайте ответ в таблицу для запоминания.

## Задача 6. Мини-проект

Напишите локальный маршрут с ответом 202, JSON-телом и заголовком корреляции. Отдельно проверьте код состояния, тип содержимого, выбранный заголовок и тело.
