# Практика: Attachments и lifecycle артефактов

## 1. Контракт вложения
Выберите имя и content type для безопасного JSON с итогом API-запроса.

## 2. Предскажите результат
Код вызывает `testInfo.attach()` без `await` и сразу удаляет временный исходный файл. Какой риск возникает?

## 3. Безопасный payload
Сократите ответ до полей `taskId`, `status`, `correlationId`; исключите token и персональные данные.

## 4. Lifecycle
Создайте временный файл через `testInfo.outputPath()`, прикрепите его и удалите в `finally`.

## 5. Automation QA-задача
Определите, какие metadata запроса и ответа прикладывать при негативном API-сценарии и чего вложение не доказывает.

## 6. Мини-проект: политика артефактов
Опишите и реализуйте правила именования, ограничения размера, маскирования, удаления временного исходного файла и срока хранения для JSON- и текстовых вложений.
