# Практика: Built-in fixtures

## Задача 1. Концептуальные вопросы

Объясните роли `browser`, `context` и `page`. Какие из этих fixtures обычно имеют test scope, а какая — worker scope?

## Задача 2. Анализ владения

Тест получает переданный `context`, затем создаёт второй контекст через `browser.newContext()`. Кто должен закрыть каждый ресурс и почему?

## Задача 3. Предскажите результат

Тест A записал cookie через свою `page`. Тест B в том же worker получает новую `page`. Увидит ли тест B эту cookie и влияет ли общий `browser` на ответ?

## Задача 4. Поиск ошибки

Тест вызывает `await browser.close()` после проверки. Следующий тест падает до выполнения проверки. Найдите нарушение жизненного цикла и предложите исправление.

## Задача 5. Automation QA

Для проверки двух независимых ролей в одном сценарии нужны два контекста. Опишите подготовку, проверки и гарантированную очистку без глобальных переменных.

## Задача 6. Мини-проект

Напишите тест Playwright, который получает `browser`, вручную создаёт два контекста, открывает по странице в каждом, задаёт разный HTML и доказывает независимость. Закройте ручные ресурсы при любом результате.
