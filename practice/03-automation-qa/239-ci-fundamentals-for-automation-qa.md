# Практика: CI fundamentals для Automation QA

## 1. CI, доставка и развёртывание
Объясните, что подтверждает CI, чем он отличается от непрерывной доставки и непрерывного развёртывания и почему успешный pipeline не означает отсутствия дефектов.

## 2. Чистый runner
Найдите скрытые предпосылки запуска, если тест работает только после ручной установки пакета и при наличии старого browser cache.

## 3. `npm ci`
Сравните контракт `npm ci` и `npm install` при авторитетном lockfile. Укажите ожидаемый результат при расхождении manifest и lockfile.

## 4. Exit code и timeout
Предскажите результат этапов с кодами завершения `0`, `2`, `0`. Объясните, что сообщает timeout job и чего он не доказывает.

## 5. Automation QA-задача
Составьте порядок недорогих статических проверок и браузерных тестов так, чтобы ранний дефект конфигурации не требовал установки браузера.

## 6. Мини-проект: CI-контракт
Опишите версию runtime, команды установки, проверки и тестов, timeout и диагностические материалы для чистого runner. Укажите владельца каждого результата.
