# Практика: Сверка данных PostgreSQL с API и gRPC

## 1. Каноническая модель

Объясните, зачем строку базы данных и транспортную модель приводят к общей форме.

## 2. Предскажите результат

PostgreSQL возвращает `estimated_hours` как `"3.75"`, а API — как `3.75`. Что даст строгое сравнение без нормализации?

## 3. Отладка сравнения времени

Исправьте сравнение строки локального времени с временной меткой UTC в формате ISO.

## 4. Реализация преобразования

Преобразуйте `snake_case`, `numeric`, `timestamptz` и `NULL` в типизированную прикладную запись.

## 5. Выбор бизнес-полей

Определите, какие поля задачи следует сравнить между базой данных и gRPC, а какие служебные столбцы хранения исключить.

## 6. Мини-проект: межслойная диагностика

Сопоставьте модели по стабильному ID и сформируйте полезное сообщение о различающихся бизнес-полях.
