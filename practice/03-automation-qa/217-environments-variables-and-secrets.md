# Практика: Окружения, переменные и secrets

## 1. Обязательные и необязательные значения
Разделите `QA_ENV`, `QA_API_TOKEN` и необязательный timeout по правилам загрузки.

## 2. Предскажите результат
Загрузчик подставляет production endpoint по умолчанию. Переменная отсутствует. Какой риск возникает?

## 3. Диагностика утечки
Код выводит `console.log(process.env)`. Объясните проблему и предложите диагностический объект со значением `[REDACTED]` вместо token.

## 4. Реализация обязательного значения
Напишите функцию, которая принимает `string | undefined`, удаляет пробелы и выбрасывает понятную ошибку для пустого значения.

## 5. Локальное и внешнее окружение
Объясните, почему способ передачи секрета может отличаться, а контракт загрузчика должен оставаться одним.

## 6. Мини-проект: безопасный ввод окружения
Создайте чистый загрузчик для тестового URL и token, разрешите только `local` и `preview`, добавьте маскирование без изменения `process.env`.
