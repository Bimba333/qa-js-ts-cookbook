# Практика: Интеграция UI-слоя

## Задача 1. Концептуальные вопросы

Опишите поток зависимостей от Playwright Test до сценария теста. Кто владеет жизненным циклом Page Object и Component Object?

## Задача 2. Анализ архитектуры

Fixture создаёт `OrdersPage`, Page Object содержит `HeaderComponent`, а тест выполняет `createOrder()` и проверку. Оцените направление зависимостей и видимость смысла бизнес-сценария.

## Задача 3. Предскажите результат

Worker-scoped fixture пытается зависеть от test-scoped `page`. Допустит ли Playwright такую зависимость между разными областями и в чём архитектурная проблема?

## Задача 4. Поиск ошибки

Все Page Objects являются singletons и получают текущую Page через изменяемую глобальную переменную. Найдите нарушения владения и изоляции и предложите композицию с test scope.

## Задача 5. Automation QA

Проведите проверку UI-слоя по шести критериям: владение, направление зависимостей, область fixture, граница Page Object и Component Object, изоляция аутентификации и читаемость теста.

## Задача 6. Мини-проект

Создайте типизированную fixture, которая предоставляет Page Object с вложенным Component Object и ролью пользователя. Напишите локальный тест, где бизнес-действие и ключевая проверка остаются видимыми, а общее изменяемое состояние отсутствует.
