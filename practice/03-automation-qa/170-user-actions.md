# Практика: Пользовательские действия

## Задача 1. Концептуальные вопросы

Что проверяют actionability checks и почему direct DOM manipulation не заменяет пользовательское действие?

## Задача 2. Выбор действия

Выберите методы для ввода текста, установки checkbox, выбора option, наведения и отправки Enter.

## Задача 3. Предскажите результат

Checkbox уже отмечен. Что гарантирует `check()` и чем слепой `click()` отличается по намерению?

## Задача 4. Debugging

В коде используются `click({ force: true })` и пропущенный `await`. Исправьте базовый сценарий и объясните, что расследовать при ошибке обычного `click()`.

## Задача 5. Automation QA

Форма сохраняется только после выбора формата и установки согласия. Запишите последовательность действий и наблюдаемую проверку результата.

## Задача 6. Мини-проект

Создайте локальную форму с полем ввода, checkbox, select и кнопкой. Заполните её подходящими действиями и проверьте сообщение `Настройки сохранены`.
