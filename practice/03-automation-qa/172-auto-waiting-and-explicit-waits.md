# Практика: Auto-waiting и явные ожидания

## Задача 1. Концептуальные вопросы

Разделите auto-waiting действий, повторные попытки web-first assertions и явные ожидания по решаемым задачам.

## Задача 2. Выбор условия

Выберите наблюдаемое условие после отправки отчёта: фиксированная пауза, видимый статус `Готов`, конкретный ответ или `networkidle`. Объясните, от чего зависит выбор.

## Задача 3. Предскажите результат

Кнопка появляется через 50 мс. Нужен ли `waitForTimeout` перед `locator.click()` и почему?

## Задача 4. Debugging

Замените `await page.waitForTimeout(3000)` перед проверкой сообщения на condition-based ожидание.

## Задача 5. Automation QA

Объясните, почему `networkidle` не доказывает готовность dashboard с фоновыми соединениями.

## Задача 6. Мини-проект

Создайте локальную кнопку, после которой результат становится видимым через управляемый timer. Синхронизируйте тест только по видимости результата.
