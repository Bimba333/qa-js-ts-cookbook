# Практика: Отчётность в Allure

## 1. Граница адаптера
Объясните разницу между адаптером Allure, результатами Allure и готовым HTML-отчётом.

## 2. Предскажите результат
Тест создаёт Playwright step и повторяет тот же шаг через Allure API. Как это повлияет на отчёт?

## 3. Labels и links
Выберите стабильные owner, feature и ссылку на test case. Не помещайте динамический token в label.

## 4. Attachment
Добавьте безопасное JSON-вложение через Allure API с корректным content type.

## 5. Automation QA-задача
Объясните, что history показывает о прошлых запусках и почему он не доказывает первопричину.

## 6. Мини-проект: результаты Allure
Подключите `allure-playwright` как готовый адаптер, выполните локальный тест и проверьте labels, link и attachment в результатах без реализации custom reporter.
