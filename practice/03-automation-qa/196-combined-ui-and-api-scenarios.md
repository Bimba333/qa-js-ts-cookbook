# Практика: Совместные UI и API-сценарии

## Задача 1. Концептуальные вопросы

Когда API должен выполнять подготовку или очистку UI-теста? Как сохранить UI предметом проверки?

## Задача 2. Анализ идентификатора

Подготовка через API возвращает ID, но UI ищет ресурс по неуникальному `title`. Найдите источник ложноположительного результата и предложите явную связь слоёв.

## Задача 3. Предскажите результат

Действие через UI создало ресурс, проверка через API прошла, затем UI-проверка упала до очистки. Что должно гарантировать удаление?

## Задача 4. Поиск ошибки

Fixture скрывает подготовку через API, действие через UI, проверку через API и очистку в одном методе `runScenario()`. Верните смысл и ключевые проверки в тест.

## Задача 5. Automation QA

Спроектируйте два сценария: подготовка через API → проверка через UI и действие через UI → проверка через API. Укажите владельца идентификатора и очистки.

## Задача 6. Мини-проект

На локальном сервере выполните действие через Page, дождитесь отображения ID, прочитайте ресурс через fixture `request` и удалите его через API в `finally`.
