# Практика: Page Object

## Задача 1. Концептуальные вопросы

Разделите ответственности сценария теста и Page Object. Где должны находиться Locators, пользовательские действия и ключевые проверки бизнес-сценария?

## Задача 2. Анализ API

Сравните методы `clickSubmit()` и `loginAs(email)`. Какой лучше выражает намерение пользователя и при каких условиях низкоуровневый метод всё же допустим?

## Задача 3. Предскажите результат

Page Object хранит Locator поля, затем страница повторно рендерит форму. Сможет ли Locator найти новый элемент при следующем действии и почему?

## Задача 4. Поиск ошибки

Класс `ApplicationPage` содержит методы для входа, заказов, отчётов и настроек администратора. Определите признаки объекта с чрезмерной ответственностью и предложите границы без универсальной структуры папок.

## Задача 5. Automation QA

Спроектируйте публичный API `OrdersPage` для открытия заказа и создания нового заказа. Укажите, какие детали селекторов останутся внутренними и какие проверки останутся в тесте.

## Задача 6. Мини-проект

Реализуйте `ProfilePage` с Locators имени и кнопки сохранения, методами `open()` и `changeName()`. Напишите тест с видимой проверкой результата сохранения.
