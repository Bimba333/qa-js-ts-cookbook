# Практика: Browser, BrowserContext и Page

## Задача 1. Концептуальные вопросы

Опишите роли `Browser`, `BrowserContext` и `Page` и владельца cookies и storage.

## Задача 2. Классификация

Для двух пользователей и двух вкладок первого пользователя определите минимальное количество `Browser`, `BrowserContext` и `Page`.

## Задача 3. Предскажите результат

В контексте A записан `localStorage.role = "admin"`. Контекст B открывает страницу того же origin. Какое значение увидит B и почему?

## Задача 4. Debugging

Найдите утечку ресурса:

```ts
const context = await browser.newContext();
const page = await context.newPage();
await page.setContent("<h1>Профиль</h1>");
```

Предложите безопасную структуру освобождения ресурсов.

## Задача 5. Automation QA

Объясните, почему новый `BrowserContext` изолирует авторизацию браузера, но не удаляет созданный заказ из серверной части.

## Задача 6. Мини-проект

Создайте два контекста, запишите `sessionStorage` только в первом, проверьте разные значения и гарантированно закройте оба контекста.
