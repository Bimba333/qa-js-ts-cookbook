# Практика: Структура HTTP-запроса

## Задача 1. Концептуальные вопросы

Назовите назначение URL, параметра пути, параметра строки запроса, заголовка, типа содержимого и тела запроса.

## Задача 2. Анализ запроса

Разберите запрос `POST /tasks?source=qa` с заголовком `x-test-role: auditor` и JSON-телом. Какая часть выбирает ресурс, уточняет обращение и передаёт данные?

## Задача 3. Предскажите результат

Тест отправляет JSON-текст с `Content-Type: text/plain`. Какие уровни контракта могут отклонить такой запрос и почему код состояния нельзя предсказать без спецификации API?

## Задача 4. Поиск ошибки

Строка запроса строится как `"?title=" + title`, где `title` содержит пробел и `&`. Исправьте стратегию с помощью параметров API-клиента.

## Задача 5. Automation QA

Составьте запрос поиска задач со статусом, владельцем и безопасным тестовым заголовком. Не помещайте учётные данные в URL и объясните выбор каждой части.

## Задача 6. Мини-проект

Создайте локальный маршрут `/inspect` и тест, который передаёт `params`, `headers` и `data`, а затем проверяет разобранные части запроса.
