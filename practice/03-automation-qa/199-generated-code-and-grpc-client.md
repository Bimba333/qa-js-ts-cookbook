# Практика: Сгенерированный код и создание gRPC Client

## Задача 1. Концептуальные вопросы

Какие задачи решают генератор, proto loader, сгенерированный client и channel? Кто отвечает за время жизни client?

## Задача 2. Анализ генерации

Два разработчика запускают разные незадокументированные команды генерации. Какие расхождения возможны и как сделать результат воспроизводимым?

## Задача 3. Предскажите результат

Client создан, вызов завершён, но `client.close()` не выполнен. Как это может повлиять на процесс тестового раннера?

## Задача 4. Поиск ошибки

Бизнес-helper добавлен прямо в сгенерированный файл service. Перенесите ответственность в корректный слой.

## Задача 5. Automation QA

Распределите ответственность за configuration endpoint, сгенерированный client, обёртку ресурса и fixture.

## Задача 6. Мини-проект

Сгенерируйте объявления TypeScript из локального `.proto`, создайте типизированный client, дождитесь его готовности, выполните call и освободите channel.
