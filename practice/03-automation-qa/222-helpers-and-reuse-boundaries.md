# Практика: Helpers и границы повторного использования

## 1. Предметная и техническая функция
Классифицируйте построение параметров запроса и маскирование секрета.

## 2. Предскажите результат
Вспомогательная функция читает глобальный client модуля, закрытый предыдущим тестом. Почему следующий вызов зависит от порядка?

## 3. Диагностика свалки функций
Файл `utils.ts` содержит авторизацию, форматирование даты, очистку базы данных и проверки. Предложите границы.

## 4. Реализация узкого API
Напишите чистую вспомогательную функцию, которая строит параметры поиска задачи и не выполняет запрос.

## 5. Побочные эффекты
Объясните, какие зависимости должны быть аргументами вспомогательной функции с I/O.

## 6. Мини-проект: решение о переиспользовании
Для трёх повторяющихся фрагментов выберите локальный код, предметную или техническую вспомогательную функцию и обоснуйте причину изменения.
