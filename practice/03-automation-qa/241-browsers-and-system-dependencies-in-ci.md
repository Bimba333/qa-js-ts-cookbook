# Практика: Browsers и системные зависимости в CI

## 1. Два вида установки
Объясните, почему `npm ci` не заменяет `npx playwright install --with-deps chromium`.

## 2. Версия браузера
Определите источник ожидаемой revision браузера и риск использования browser cache от другой версии Playwright.

## 3. Граница headless mode
Объясните, почему headless execution всё равно требует исполняемый файл браузера и системные зависимости.

## 4. Классификация падения
Браузер не запустился из-за отсутствующей библиотеки Linux. Классифицируйте этот диагностический признак и объясните, почему retry теста не исправляет причину.

## 5. Automation QA-задача
Расположите `npm ci`, установку браузера и браузерный тест в правильном порядке. Укажите, какой этап должен завершиться до следующего.

## 6. Мини-проект: browser job
Создайте workflow fixture с Node.js 22, `npm ci`, установкой Chromium с системными зависимостями и проверкой браузерного окружения. Добавьте минимальные permissions и timeout.
