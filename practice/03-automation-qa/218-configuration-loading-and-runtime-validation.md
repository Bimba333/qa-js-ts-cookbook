# Практика: Загрузка и runtime validation конфигурации

## 1. Этапы загрузчика
Объясните обязанности чтения, удаления внешних пробелов, разбора и runtime validation.

## 2. Предскажите результат
Выполняется `const timeout: number = Number("slow")`. Какое значение получится во время выполнения и почему аннотация типа не защищает запуск?

## 3. Диагностика type assertion
Найдите проблему в `process.env as unknown as RuntimeConfig`.

## 4. Реализация числового поля
Напишите функцию разбора положительного целого timeout с диагностикой имени поля.

## 5. Раннее завершение
Объясните, почему загрузчик следует вызвать до создания ресурсов браузера, API и базы данных.

## 6. Мини-проект: типизированная конфигурация
Создайте загрузчик с объединением `local | preview`, строковым полем URL, необязательным timeout и обязательным token. Верните readonly-результат, замороженный через `Object.freeze()`, и проверьте успешный и два ошибочных входа.
