# Практика: Изоляция UI-тестов и состояние браузера

## Задача 1. Концептуальные вопросы

Различите браузерное и серверное состояние. Что изолирует свежий `BrowserContext`?

## Задача 2. Анализ зависимости

Первый тест создаёт пользователя, второй входит под ним. Почему второй тест зависит от порядка и как изменить владение подготовкой?

## Задача 3. Предскажите результат

Контекст A записал cookie и `localStorage`. Что увидит независимый контекст B того же браузера?

## Задача 4. Debugging

Два параллельных теста редактируют заказ `order-1`. Определите источник flaky behavior и предложите стратегию данных.

## Задача 5. Automation QA

Сформулируйте три проверки независимости теста: одиночный запуск, произвольный порядок и запуск рядом с другими тестами.

## Задача 6. Мини-проект

Создайте два контекста с одним origin, запишите `sessionStorage` только в одном и докажите изоляцию. Объясните, почему пример ничего не доказывает о данных серверной части.
