# Практика: CI jobs, sharding и диагностика запусков

## 1. Matrix и shard
Объясните различия между расширением matrix, отдельным runner, Playwright project, worker и sharding. Укажите число jobs для matrix `shard: [1, 2]`.

## 2. Покрытие
Для четырёх тестов проверьте shards `1/2` и `2/2`: ожидаемое количество тестов в каждом сегменте, общее количество уникальных тестов, дубликаты и пропуски.

## 3. Идентификаторы artifacts
Создайте имя artifact, включающее идентификатор shard. Объясните, почему одинаковое имя создаёт конфликт принадлежности результатов.

## 4. Fail-fast
Объясните влияние `strategy.fail-fast: false` на диагностику одного упавшего shard и почему это не превращает падение в успех.

## 5. Automation QA-задача
Составьте план сравнения падения только в CI между pull request, запуском по расписанию и локальным запуском без автоматического вывода о дефекте продукта.

## 6. Мини-проект: sharded pipeline
Создайте ограниченную matrix из двух jobs с `--shard=1/2` и `--shard=2/2`, уникальными artifacts и полным покрытием. Объединение результатов оставьте отдельной концептуальной границей.
