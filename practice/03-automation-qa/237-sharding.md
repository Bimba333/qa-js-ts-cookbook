# Практика: Sharding

## 1. Идентификатор shard
Объясните `--shard=1/3` и допустимые значения номера и общего количества сегментов.

## 2. Независимость shards
Почему shard 2 не должен ожидать подготовку данных, выполненную shard 1?

## 3. Баланс распределения
Предложите способ выявить дисбаланс по числу и длительности тестов без реализации CI.

## 4. Общий ресурс
Разделите имя файла и пространство имён внешних учётных записей между двумя shards.

## 5. Automation QA-задача
Опишите объединение результатов так, чтобы падение одного shard не потерялось.

## 6. Мини-проект: два локальных shard
Запустите независимый набор с `--shard=1/2` и `--shard=2/2`; проверьте четыре уникальных теста без пересечений, пропусков и остаточного состояния.
