## Задача 2. Анализ message

Response содержит `priority = TASK_PRIORITY_UNSPECIFIED` и пустой `labels`. Какие выводы тест может и не может сделать без бизнес-контракта?

## Задача 3. Предскажите результат

`Optional`-поле `description` отсутствует, а обычное поле `completed` не передано. Какие значения увидит loader с параметрами `defaults` и `oneofs`?

## Задача 4. Поиск ошибки

Тест сравнивает снимок всего сгенерированного response, хотя важны только ID, `priority` и `owner`. Перепишите проверку по смыслу.

## Задача 5. Automation QA

Составьте проверки для repeated-поля `labels`, enum `priority`, `optional`-поля `description` и вложенного `owner`.

## Задача 6. Мини-проект
