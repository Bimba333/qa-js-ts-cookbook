# Практика: Вкладки, окна и popups

## Задача 1. Концептуальные вопросы

Чем popup отличается от frame? Когда ждать `popup` у `page`, а когда новую `page` у `context`?

## Задача 2. Анализ синхронизации

Запишите правильный порядок операций для кнопки, открывающей отчёт в новой вкладке: ожидание, действие, получение Page, проверка, очистка.

## Задача 3. Предскажите результат

Тест сначала кликает кнопку, затем вызывает `page.waitForEvent("popup")`. Какая гонка событий возможна?

## Задача 4. Поиск ошибки

Тест всегда берёт последнюю Page из `context.pages()` после клика. Объясните, почему это ненадёжно при нескольких одновременных окнах, и предложите решение на основе события.

## Задача 5. Automation QA

Спроектируйте сценарий предварительного просмотра отчёта: исходная Page остаётся открытой, popup проверяется и закрывается даже при неуспешной проверке.

## Задача 6. Мини-проект

Создайте локальный HTML с кнопкой `window.open()`. Синхронизированно получите popup, проверьте заголовок, убедитесь, что он принадлежит тому же контексту, и гарантированно закройте его.
