# Практика: Web-first assertions

## Задача 1. Концептуальные вопросы

Чем web-first assertion над `Locator` отличается от проверки однажды прочитанного значения?

## Задача 2. Выбор проверки

Подберите проверки для видимости уведомления, текста статуса, значения поля ввода, отмеченного checkbox и количества строк.

## Задача 3. Предскажите результат

Текст меняется с `Обработка` на `Готово` через 80 мс. Почему `await expect(locator).toHaveText("Готово")` может пройти без ручной паузы?

## Задача 4. Debugging

Исправьте ненадёжную проверку:

```ts
const text = await page.getByLabel("Статус").textContent();
expect(text).toBe("Готово");
```

## Задача 5. Automation QA

После сохранения профиль показывает toast и активирует кнопку `Продолжить`. Какие проверки выражают бизнес-результат лучше проверки CSS-класса?

## Задача 6. Мини-проект

Создайте локальный интерфейс, который асинхронно меняет статус и добавляет две строки. Проверьте текст и количество через web-first assertions.
