# Практика: Metadata и аутентификация gRPC

## Задача 1. Концептуальные вопросы

Чем metadata отличается от request message? Чем аутентификация отличается от авторизации?

## Задача 2. Анализ доступа

Отсутствующий token и допустимый read-only token оба приводят к `UNAUTHENTICATED`. Найдите семантическую ошибку и назначьте статусы.

## Задача 3. Предскажите результат

Один изменяемый `Metadata` используется параллельно двумя тестами, и второй меняет authorization. Какой риск появляется?

## Задача 4. Поиск ошибки

Helper записывает весь объект metadata в лог при отказе. Сохраните диагностику без раскрытия данных доступа.

## Задача 5. Automation QA

Спроектируйте сценарии с допустимым, отсутствующим и недействительным token, а также с недостаточными правами. Используйте учебные tokens и correlation ID.

## Задача 6. Мини-проект

Передайте authorization и correlation ID через `Metadata`, проверьте начальные metadata ответа и точные status ошибок.
