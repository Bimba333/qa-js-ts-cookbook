1. Что делает этот файл на уровне результата?
2. Какой командой его можно запустить, если файл сохранен как `playground/environment-check.js`?
3. Что нужно проверить, если файл не запускается?

## Предскажите результат перед запуском

Создайте файл:

```text
playground/predict-output.js
```

Добавьте код:

```javascript
console.log('First run');
console.log('Second run');
```

Перед запуском запишите, какой вывод ожидаете увидеть в терминале.

Затем запустите файл и сравните ожидание с фактическим результатом.

## Написание небольшого кода

Создайте файл:

```text
playground/qa-message.js
```

Добавьте одну строку кода, которая выводит в терминал:

```text
QA environment is ready
```

Запустите файл через Node.js.

### Задача 2

Checklist должен включать:

* проверку Node.js;

## Мини-проект

Создайте личный файл проверки окружения в `playground/`.

Требования:

* файл должен иметь расширение `.js`;
* файл должен выводить одну строку в терминал;
* перед запуском нужно записать ожидаемый результат;
* после запуска нужно записать фактический результат;
* если возникла ошибка, нужно описать гипотезу и проверку.

Формат заметки свободный. Главное — показать ход диагностики.
