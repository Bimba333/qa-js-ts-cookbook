# Практика. Глава 1. Как пользоваться курсом

## Проверка понимания

Ответьте своими словами.

1. Почему чтение главы без запуска примеров дает слабый результат?
2. Почему порядок глав важен для понимания следующих тем?
3. Что нужно сделать перед запуском примера кода?
4. Почему решения нужно читать после собственной попытки?
5. Для чего используется `playground/`?
6. Чем личная заметка отличается от копии текста главы?
7. Как правильно возвращаться к сложной теме?
8. Почему Automation QA Engineer должен связывать каждую тему с тестовым кодом?

## Анализ кода

Прочитайте код и предскажите результат до запуска.

```javascript
let retryCount = 0;

function increaseRetryCount() {
  retryCount = retryCount + 1;
}

increaseRetryCount();

console.log(retryCount);
```

Ответьте:

1. Что будет выведено в консоль?
2. Какая строка изменила значение?
3. Какой маленький эксперимент можно сделать с этим примером?

## Написание кода

Напишите минимальный пример, который можно использовать для учебного эксперимента.

Требования:

* пример должен проверять одну идею;
* имена переменных должны быть осмысленными;
* перед кодом запишите ожидаемый результат;
* после кода запишите, как вы проверите результат в `playground/`.

## Поиск ошибок

Найдите ошибку в подходе.

```text
Я прочитаю всю главу, потом сразу открою решения.
Если решение понятно, значит тему можно считать изученной.
```

Объясните:

1. Какая часть подхода неверна?
2. Почему ощущение понятности не равно пониманию?
3. Как нужно изменить процесс обучения?

## Мини-проект

Создайте шаблон личной заметки для прохождения глав курса.

Шаблон должен включать:

* название главы;
* главную идею;
* механизм;
* минимальный пример;
