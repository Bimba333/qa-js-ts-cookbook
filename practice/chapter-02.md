## Анализ кода

Прочитайте код.

```javascript
function buildUserEndpoint(baseUrl, userId) {
  return `${baseUrl}/users/${userId}`;
}

const endpoint = buildUserEndpoint('https://api.example.com', 'user-7');

console.log(endpoint);
```

Ответьте:

1. Что будет выведено в консоль?
2. Какие базовые темы JavaScript здесь используются?
3. Как этот пример может вырасти в часть API layer?

## Написание кода

Напишите минимальный пример функции, которая собирает URL для заказа.

Требования:

* функция должна принимать `baseUrl` и `orderId`;
* функция должна возвращать строку endpoint;

## Мини-проект

Создайте личную карту курса.

Карта должна включать:

* пять крупных частей курса;
* по 2-3 ключевые темы в каждой части;
* одну зависимость между соседними частями;
* одну QA-задачу, которая требует знаний из нескольких частей;
* место финального проекта в общей структуре.

Формат свободный. Можно использовать ASCII-схему или таблицу.
