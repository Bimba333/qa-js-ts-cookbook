# Решения: Attachments и lifecycle артефактов

## 1. Контракт вложения
### Ответ
Имя `task-response-summary`, content type `application/json`.
### Объяснение
Имя описывает сущность, а content type позволяет reporter корректно представить данные.
### Типичная ошибка
Назвать вложение `data`.
### Связь с Automation QA
Доказательство быстро находится в результате теста.

## 2. Предскажите результат
### Ответ
Копирование может не завершиться до удаления, поэтому вложение потеряется или завершится ошибкой.
### Объяснение
`attach()` для path нужно ожидать.
### Типичная ошибка
Считать вызов синхронным.
### Связь с Automation QA
Жизненный цикл исходного файла учитывает завершение копирования.

## 3. Безопасный payload
### Ответ
Прикладывается `{ taskId, status, correlationId }`; чувствительные поля удаляются до сериализации.
### Объяснение
Минимальные данные отвечают вопросу расследования.
### Типичная ошибка
Маскировать token только после записи.
### Связь с Automation QA
Report не становится копией production payload.

## 4. Lifecycle
### Ответ
Получите path через `testInfo.outputPath()`, выполните `writeFile`, `await testInfo.attach(...)`, затем `rm(path, { force: true })` в `finally`.
### Объяснение
Reporter получает собственную копию, а временный исходный файл удаляется.
### Типичная ошибка
Использовать общий `/tmp/result.json`.
### Связь с Automation QA
Параллельные тесты не конфликтуют по пути.

## 5. Automation QA-задача
### Ответ
Прикладываются method, path, status, идентификатор сценария и безопасный error code. Они не доказывают внутреннее состояние приложения.
### Объяснение
Вложение фиксирует наблюдаемый результат транспорта.
### Типичная ошибка
Приравнять HTTP response к database state.
### Связь с Automation QA
Каждый слой предоставляет собственные доказательства.

## 6. Мини-проект: политика артефактов
### Ответ
Политика задаёт предметные имена, content types, ограничение размера, маскирование до записи, временные пути конкретного теста и срок хранения на границе хранилища.
### Объяснение
Правила отделены от случайных решений теста.
### Типичная ошибка
Удалять копию, принадлежащую reporter, из теста.
### Связь с Automation QA
Жизненный цикл остаётся предсказуемым.
