# Решения: Browsers и системные зависимости в CI

## 1. Два вида установки
### Ответ
`npm ci` устанавливает npm-пакеты. `npx playwright install --with-deps chromium` устанавливает совместимый Chromium и системные библиотеки Linux.
### Объяснение
Пакет и исполняемый файл браузера имеют разные жизненные циклы.
### Типичная ошибка
Ожидать установленный браузер после одного `npm ci`.
### Связь с Automation QA
Установка браузера становится явным шагом CI.

## 2. Версия браузера
### Ответ
Ожидаемую revision определяет установленная версия Playwright из lockfile. Cache другой версии может вернуть несовместимый исполняемый файл.
### Объяснение
Ключ cache должен учитывать версию Playwright и ОС.
### Типичная ошибка
Использовать бессрочный общий browser cache.
### Связь с Automation QA
Сбой запуска классифицируется по данным о пакете и браузере.

## 3. Граница headless mode
### Ответ
Браузер в headless mode не показывает окно, но остаётся исполняемым процессом с системными зависимостями.
### Объяснение
Режим отображения не отменяет требования runtime.
### Типичная ошибка
Считать headless тест чистым Node.js-кодом.
### Связь с Automation QA
CI runner готовится до запуска fixture `page`.

## 4. Классификация падения
### Ответ
Это сбой инфраструктуры или конфигурации до выполнения assertions. Retry повторит ту же неполную подготовку и не установит библиотеку.
### Объяснение
Статус runner не доказывает нестабильность теста.
### Типичная ошибка
Увеличить retries вместо восстановления environment.
### Связь с Automation QA
Ошибка направляется владельцу образа CI или шага подготовки.

## 5. Automation QA-задача
### Ответ
`npm ci` → `npx playwright install --with-deps chromium` → браузерный тест. Каждый step обязан завершиться с кодом `0`.
### Объяснение
CLI для установки браузера появляется после установки пакета.
### Типичная ошибка
Устанавливать browser неизвестной глобальной версией Playwright.
### Связь с Automation QA
Revision пакета и браузера остаются согласованными.

## 6. Мини-проект: browser job
### Ответ
Fixture главы 241 использует `contents: read`, Node.js 22, timeout 20 минут, `npm ci`, `npx playwright install --with-deps chromium` и `npm run test:playwright`.
### Объяснение
Он выражает полную подготовку чистого Linux runner.
### Типичная ошибка
Скрывать установку браузера в ручной инструкции.
### Связь с Automation QA
Bootstrap проверяет реальный запуск браузера.
