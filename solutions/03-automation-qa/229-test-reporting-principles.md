# Решения: Принципы тестовой отчётности

## 1. Контракт отчёта
### Ответ
Нужны стабильные title и case ID, status, duration, предметные steps, исходная ошибка, безопасное имя окружения, links и owner.
### Объяснение
Каждое поле отвечает на отдельный вопрос читателя отчёта.
### Типичная ошибка
Ограничиться одним status.
### Связь с Automation QA
Разработка и QA получают общий контекст.

## 2. Предскажите результат
### Ответ
Нет, reporter видит только события, которые runner и тест передали ему.
### Объяснение
Он не может восстановить бизнес-намерение из произвольного вызова helper.
### Типичная ошибка
Ожидать автоматические предметные steps.
### Связь с Automation QA
Намерение задаётся в test title и `test.step()`.

## 3. Названия steps
### Ответ
Например: «Создать задачу через API» и «Проверить статус задачи в UI».
### Объяснение
Названия описывают цель, а не реализацию.
### Типичная ошибка
Создать step для каждого locator.
### Связь с Automation QA
Отчёт сохраняет читаемый сценарий.

## 4. Error details
### Ответ
`throw new Error("Не удалось получить task-229", { cause: error })` после безопасной проверки значения типа `unknown`.
### Объяснение
`cause` сохраняет исходную ошибку и цепочку stack trace.
### Типичная ошибка
Выбросить новый общий `Error` без cause.
### Связь с Automation QA
Сведения о падении остаются полезными.

## 5. Automation QA-задача
### Ответ
Annotations содержат owner, `local` или `preview` и URL test case; credentials исключены.
### Объяснение
Идентичность окружения отличается от секретных значений.
### Типичная ошибка
Прикладывать весь `process.env`.
### Связь с Automation QA
Отчёт безопасно направляет результат владельцу.

## 6. Мини-проект: полезный отчёт
### Ответ
Тест получает устойчивый title, два предметных steps, annotations владельца и окружения, границу `Error.cause` и JSON-вложение с разрешёнными полями.
### Объяснение
Контракт строится из событий runner, а не из логики custom reporter.
### Типичная ошибка
Дублировать assertion ради отчёта.
### Связь с Automation QA
Один сценарий остаётся источником истины.
