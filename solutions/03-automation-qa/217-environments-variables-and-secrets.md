# Решения: Окружения, переменные и secrets

## 1. Обязательные и необязательные значения
### Ответ
`QA_ENV` и `QA_API_TOKEN` обязательны; timeout может иметь безопасное тестовое значение по умолчанию.
### Объяснение
Без окружения и token запуск не определён, а timeout имеет локальное значение по умолчанию.
### Типичная ошибка
Давать token пустой строкой.
### Связь с Automation QA
Раннее завершение отделяет ошибку запуска от дефекта продукта.

## 2. Предскажите результат
### Ответ
Тесты молча направятся в production, если переменная отсутствует.
### Объяснение
Неявное значение по умолчанию превращает ошибку конфигурации в опасное поведение.
### Типичная ошибка
Считать любое значение по умолчанию безопасным.
### Связь с Automation QA
Production никогда не выбирается неявно.

## 3. Диагностика утечки
### Ответ
Нужно выводить только заранее разрешённые поля, заменяя token целиком на `[REDACTED]`.
### Объяснение
`process.env` может содержать учётные данные других инструментов.
### Типичная ошибка
Удалять только одно известное поле из полного объекта.
### Связь с Automation QA
Лог сообщает окружение и URL без секрета.

## 4. Реализация обязательного значения
### Ответ
```ts
function required(value: string | undefined, name: string): string {
  const normalized = value?.trim();
  if (!normalized) throw new Error(`Обязательная переменная ${name} не задана`);
  return normalized;
}
```
### Объяснение
Пустая и отсутствующая строки одинаково нарушают требование обязательного значения.
### Типичная ошибка
Проверять только `value === undefined`.
### Связь с Automation QA
Диагностика называет точную настройку.

## 5. Локальное и внешнее окружение
### Ответ
Источник значения различается, но загрузчик всегда принимает одинаковую пару `name -> string | undefined`.
### Объяснение
Контракт приложения не зависит от способа доставки секрета.
### Типичная ошибка
Создавать отдельную модель конфигурации для каждой машины.
### Связь с Automation QA
Одинаковая runtime validation работает локально и во внешнем runner.

## 6. Мини-проект: безопасный ввод окружения
### Ответ
Чистый загрузчик принимает объект, разрешает только `local | preview`, требует URL и token и возвращает отдельный диагностический объект с `[REDACTED]`.
### Объяснение
Глобальный `process.env` не изменяется, а неизвестное окружение не получает неявное значение.
### Типичная ошибка
Возвращать исходный объект вместе с секретом.
### Связь с Automation QA
Тест загрузчика детерминирован и не зависит от машины.
