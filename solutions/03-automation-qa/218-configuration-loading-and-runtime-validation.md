# Решения: Загрузка и runtime validation конфигурации

## 1. Этапы загрузчика
### Ответ
Чтение получает строки, нормализация удаляет внешние пробелы, разбор преобразует значения, а runtime validation проверяет контракт.
### Объяснение
Типизированная конфигурация появляется только после всех этапов.
### Типичная ошибка
Смешивать разбор и неявное значение по умолчанию.
### Связь с Automation QA
Чёткая последовательность локализует ошибку запуска.

## 2. Предскажите результат
### Ответ
Получится `NaN`; аннотация описывает переменную, но не проверяет результат `Number()`.
### Объяснение
Типы TypeScript отсутствуют во время выполнения.
### Типичная ошибка
Считать `number` гарантией конечного числа.
### Связь с Automation QA
Некорректный timeout должен остановить загрузчик конфигурации.

## 3. Диагностика type assertion
### Ответ
Type assertion без проверки объявляет внешние строки готовым `RuntimeConfig`.
### Объяснение
Поля остаются отсутствующими или имеют неверный тип во время выполнения.
### Типичная ошибка
Использовать двойное type assertion как runtime validation.
### Связь с Automation QA
Ошибка проявится далеко от источника конфигурации.

## 4. Реализация числового поля
### Ответ
```ts
function positiveInteger(value: string, name: string): number {
  const parsed = Number(value);
  if (!Number.isSafeInteger(parsed) || parsed <= 0) {
    throw new Error(`${name} должен быть положительным целым числом`);
  }
  return parsed;
}
```
### Объяснение
Проверяются форма, диапазон и целочисленность значения.
### Типичная ошибка
Принимать `NaN`, ноль или дробь.
### Связь с Automation QA
Timeout становится предсказуемым во время выполнения.

## 5. Раннее завершение
### Ответ
Загрузчик вызывается до создания дорогих ресурсов, чтобы некорректная конфигурация не выглядела как ошибка браузера, API или базы данных.
### Объяснение
Причина и сообщение остаются рядом.
### Типичная ошибка
Проверять каждое поле внутри отдельных тестов.
### Связь с Automation QA
Набор не создаёт лишние побочные эффекты.

## 6. Мини-проект: типизированная конфигурация
### Ответ
Загрузчик требует `local | preview`, проверяет URL через `URL`, сохраняет его как строку, проверяет token и положительный timeout. Корректный вход возвращает readonly-объект, замороженный через `Object.freeze()`, а неизвестное окружение и отсутствующий token вызывают разные диагностические ошибки.
### Объяснение
Успешный результат не содержит частично проверенных полей и не возвращает изменяемый объект `URL`.
### Типичная ошибка
Продолжать загрузку с неявным переходом на production.
### Связь с Automation QA
Окружение валидируется до создания ресурсов тестового сценария.
