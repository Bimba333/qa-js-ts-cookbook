# Решения: Screenshots, videos и Playwright Trace

## 1. Выбор доказательства
### Ответ
Видимый момент — screenshot; последовательность UI — video; действия, DOM snapshots и network timeline — trace.
### Объяснение
Артефакты отвечают на разные вопросы.
### Типичная ошибка
Считать их взаимозаменяемыми.
### Связь с Automation QA
Выбор уменьшает объём хранения и шум.

## 2. Предскажите результат
### Ответ
После успешного теста trace не сохраняется.
### Объяснение
`retain-on-failure` оставляет запись только при failed result.
### Типичная ошибка
Ожидать артефакт каждого запуска.
### Связь с Automation QA
Политика ограничивает объём результатов.

## 3. Ограничения доказательств
### Ответ
Screenshot подтверждает только отрисованный UI в момент снимка.
### Объяснение
Состояние database может отличаться или быть закешированным.
### Типичная ошибка
Делать backend-вывод по изображению.
### Связь с Automation QA
Backend проверяется через соответствующий API или repository.

## 4. Контролируемое падение
### Ответ
Используйте `page.setContent()`, точное несовпадающее `toHaveText` и отдельный config с выделенным для модуля `outputDir` и артефактами `retain-on-failure`.
### Объяснение
Падение детерминировано и не требует сети.
### Типичная ошибка
Строить пример на race condition.
### Связь с Automation QA
Команда должна документировать ожидаемый exit code `1`.

## 5. Automation QA-задача
### Ответ
Screenshot и trace сохраняются при падении; video включается для выбранного набора UI-тестов. Данные синтетические, срок хранения ограничен.
### Объяснение
Тяжёлые артефакты полезны не для каждого успешного запуска.
### Типичная ошибка
Хранить video бессрочно.
### Связь с Automation QA
Политика балансирует потребности расследования и стоимость хранения.

## 6. Мини-проект: доказательства UI
### Ответ
Config успешного набора исключает файл контролируемого падения; отдельный config запускает его с trace, screenshot и video. После ожидаемого exit `1` основной набор тестов снова проходит.
### Объяснение
Негативная диагностика не делает основной набор тестов красным.
### Типичная ошибка
Включить контролируемое падение в общий `testMatch`.
### Связь с Automation QA
Артефакты можно проверять независимо.
