# Решения: Анатомия и модель выполнения теста

## Задача 1. Концептуальные вопросы
### Ответ
`test()` регистрирует объявление, этап обнаружения находит подходящие объявления, worker позже выполняет выбранное тело.
### Объяснение
Загрузка файла и запуск тела теста — разные этапы.
### Типичная ошибка
Считать регистрацию немедленным выполнением.
### Связь с Automation QA
Этапы локализуют причины сообщений «тест не найден» и ошибок выполнения.

## Задача 2. Чтение кода
### Ответ
Название — `открывает отчёт`; тело — асинхронный callback; fixture — `page`; действие — `click`; проверка — `toBeVisible`. `setContent` выполняет подготовку.
### Объяснение
Структура видна по ответственности строк.
### Типичная ошибка
Называть `test()` проверкой.
### Связь с Automation QA
Читаемый поток упрощает расследование.

## Задача 3. Предскажите результат
### Ответ
Проверка завершится ошибкой, тест будет неуспешным, а запуск с неуспешным тестом вернёт ненулевой код завершения.
### Объяснение
Тестовый раннер преобразует необработанную ошибку проверки в результат.
### Типичная ошибка
Считать timeout успешным пропуском.
### Связь с Automation QA
CI использует exit code как сигнал.

## Задача 4. Debugging
### Ответ
```ts
await page.getByRole("button", { name: "Сохранить" }).click();
await expect(page.getByText("Сохранено")).toBeVisible();
```
### Объяснение
Без `await` проверка может начаться до завершения `click()`.
### Типичная ошибка
Добавлять паузу вместо ожидания Promise.
### Связь с Automation QA
Ожидаемые шаги сохраняют причинный порядок.

## Задача 5. Automation QA
### Ответ
Arrange: открыть локальную форму и подготовить данные. Act: заполнить поля и отправить. Assert: проверить подтверждение и идентификатор заказа.
### Объяснение
Модель показывает намерение, даже без комментариев.
### Типичная ошибка
Проверять детали во время каждого действия без бизнес-причины.
### Связь с Automation QA
Сценарий читается как поведение системы.

## Задача 6. Мини-проект
### Ответ
```ts
import { expect, test } from "@playwright/test";

test.describe("форма", () => {
  test("сохраняет имя", async ({ page }) => {
    await page.setContent(`<input aria-label="Имя"><button onclick="document.getElementById('result').textContent='Сохранено'">Сохранить</button><p id="result"></p>`);
    await page.getByLabel("Имя").fill("Анна");
    await page.getByRole("button", { name: "Сохранить" }).click();
    await expect(page.getByText("Сохранено")).toBeVisible();
  });
});
```
### Объяснение
Все асинхронные операции включены в жизненный цикл тела теста.
### Типичная ошибка
Пропустить `await` у `fill`.
### Связь с Automation QA
Форма моделирует типичный UI-flow без внешней сети.
