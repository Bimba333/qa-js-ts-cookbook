# Решения: Auto-waiting и явные ожидания

## Задача 1. Концептуальные вопросы
### Ответ
Auto-waiting ждёт готовность цели действия; web-first assertion — ожидаемый результат; явное ожидание — отдельное событие или состояние.
### Объяснение
Механизмы имеют разные условия успеха.
### Типичная ошибка
Называть их одной общей паузой.
### Связь с Automation QA
Выбор условия определяет надёжность сценария.

## Задача 2. Выбор условия
### Ответ
Обычно статус `Готов` лучше всего выражает пользовательский результат. Конкретный ответ нужен, если именно он разрешает следующий шаг. Фиксированная пауза не проверяет состояние, `networkidle` не универсален.
### Объяснение
Условие выбирается по смыслу готовности.
### Типичная ошибка
Ждать всю сеть вместо нужного результата.
### Связь с Automation QA
Падение указывает на отсутствующее бизнес-состояние.

## Задача 3. Предскажите результат
### Ответ
Отдельный `waitForTimeout()` не нужен: `click()` автоматически ждёт появления и actionability `Locator` в своей границе.
### Объяснение
Action сам синхронизируется с целью.
### Типичная ошибка
Добавлять sleep перед каждым действием.
### Связь с Automation QA
Тест остаётся быстрым на быстрой среде.

## Задача 4. Debugging
### Ответ
```ts
await expect(page.getByText("Отчёт готов")).toBeVisible();
```
### Объяснение
Assertion ждёт нужное наблюдаемое состояние.
### Типичная ошибка
Заменить 3000 на 5000.
### Связь с Automation QA
Сценарий связан с готовностью отчёта.

## Задача 5. Automation QA
### Ответ
Dashboard может постоянно обмениваться фоновыми данными, а UI может быть готов до или после сетевого затишья.
### Объяснение
Network activity и business readiness не эквивалентны.
### Типичная ошибка
Использовать `networkidle` как глобальный стандарт.
### Связь с Automation QA
Нужно ждать конкретный widget или status.

## Задача 6. Мини-проект
### Ответ
```ts
await page.setContent(`<button onclick="setTimeout(() => document.getElementById('result').hidden=false, 80)">Запустить</button><p id="result" hidden>Готово</p>`);
await page.getByRole("button", { name: "Запустить" }).click();
await expect(page.getByText("Готово")).toBeVisible();
```
### Объяснение
Timer принадлежит локальному приложению, тест ждёт результат.
### Типичная ошибка
Ждать длительность timer напрямую.
### Связь с Automation QA
Условие моделирует завершение операции.
