# Решения: Структурированное логирование

## 1. Состав события
### Ответ
`info`, `api.request.completed`, идентификатор сценария, ISO timestamp и поля `method`, безопасный `path`, `status`, `durationMs`.
### Объяснение
Поля восстанавливают событие без полного body и credentials.
### Типичная ошибка
Записать headers целиком.
### Связь с Automation QA
Событие фильтруется по сценарию и status.

## 2. Предскажите результат
### Ответ
Секрет уже останется в сериализованной строке или в данных, переданных logger.
### Объяснение
Маскирование после записи не изменяет предыдущую копию.
### Типичная ошибка
Маскировать значение только при отображении отчёта.
### Связь с Automation QA
Чувствительные поля заменяются до сериализации.

## 3. Выбор уровня
### Ответ
Setup — `info`; необязательный сервис — `warn`; ошибка очистки — `error`; подробная структура payload — `debug`.
### Объяснение
Level отражает влияние события, а не его эмоциональную важность.
### Типичная ошибка
Записывать всё как `error`.
### Связь с Automation QA
Фильтрация сохраняет сигнал запуска.

## 4. Отладка границы logger
### Ответ
После записи в журнал нужно повторно выбросить исходный `Error` либо обернуть его через `{ cause }`.
### Объяснение
Logger наблюдает ошибку, но не меняет поток выполнения.
### Типичная ошибка
Вернуть `undefined` и получить вторичное падение.
### Связь с Automation QA
Отчёт сохраняет исходный stack.

## 5. Automation QA-задача
### Ответ
Создайте `{ level, event, correlationId, fields: { method, path, status, durationMs } }` после маскирования.
### Объяснение
Metadata достаточно для связи с отдельным вложением при необходимости.
### Типичная ошибка
Всегда добавлять тело ответа.
### Связь с Automation QA
Записи журнала остаются компактными и безопасными.

## 6. Мини-проект: безопасный logger
### Ответ
Типизированная factory нормализует timestamp, заменяет значения ключей token, authorization, cookie, password, connection string и storage state на `[REDACTED]`. Сериализатор отмечает циклические ссылки, преобразует `BigInt` и возвращает валидный ограниченный JSON для слишком большого payload. Значения не типа `Error` описываются явно, а обход циклической цепочки `Error.cause` завершается безопасным маркером.
### Объяснение
Единая граница предотвращает расхождение форматов, ошибку сериализации и создание неограниченного вложения.
### Типичная ошибка
Искать секреты регулярным выражением только в готовой строке.
### Связь с Automation QA
Одинаковая политика применяется к событиям UI, API и database.
