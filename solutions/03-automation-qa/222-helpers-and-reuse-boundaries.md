# Решения: Helpers и границы повторного использования

## 1. Предметная и техническая функция
### Ответ
Построение параметров запроса — предметная вспомогательная функция; маскирование секрета — техническая.
### Объяснение
Первый знает терминологию задачи, второй решает инфраструктурную безопасность.
### Типичная ошибка
Помещать оба в `CommonUtils`.
### Связь с Automation QA
Названия показывают владельца изменения.

## 2. Предскажите результат
### Ответ
Вызов получит ошибку закрытого client; результат зависит от предыдущего теста.
### Объяснение
Скрытая глобальная зависимость модуля переживает локальную область жизни.
### Типичная ошибка
Пересоздавать client внутри вспомогательной функции без явного жизненного цикла.
### Связь с Automation QA
Зависимость I/O передаётся аргументом или fixture.

## 3. Диагностика свалки функций
### Ответ
Авторизация относится к своей предметной области, форматирование — к чистому преобразованию, очистка базы данных — к жизненному циклу данных, а проверки — к предметным правилам.
### Объяснение
У частей разные причины изменения и зависимости.
### Типичная ошибка
Делить файл только по размеру.
### Связь с Automation QA
Модули получают узкие public API.

## 4. Реализация узкого API
### Ответ
```ts
function taskSearch(ownerId: string, status?: string): URLSearchParams {
  const params = new URLSearchParams({ ownerId });
  if (status) params.set("status", status);
  return params;
}
```
### Объяснение
Функция выполняет одно чистое преобразование.
### Типичная ошибка
Делать `fetch` внутри построителя параметров.
### Связь с Automation QA
API Client сохраняет владение запросом.

## 5. Побочные эффекты
### Ответ
Client, logger, clock и конфигурация передаются явно, если вспомогательная функция действительно ими пользуется.
### Объяснение
Видимые зависимости делают тестирование и жизненный цикл предсказуемыми.
### Типичная ошибка
Импортировать изменяемый singleton.
### Связь с Automation QA
Fixture может предоставить зависимость с контролируемой областью жизни.

## 6. Мини-проект: решение о переиспользовании
### Ответ
Одноразовое преобразование остаётся локальным; построение запроса задачи становится предметной вспомогательной функцией; маскирование данных разных clients — технической.
### Объяснение
Решение основано на устойчивой причине изменения, а не числе строк.
### Типичная ошибка
Абстрагировать первое совпадение кода.
### Связь с Automation QA
Общий слой не превращается в свалку функций.
