# Решения: Отчётность в Allure

## 1. Граница адаптера
### Ответ
Адаптер записывает события запуска в результаты Allure; отдельный инструмент Allure строит из результатов HTML-отчёт.
### Объяснение
Результаты — данные, отчёт — их представление.
### Типичная ошибка
Ожидать HTML от адаптера reporter.
### Связь с Automation QA
Публикация остаётся отдельной операцией.

## 2. Предскажите результат
### Ответ
В отчёте появятся дублирующие шаги, и сценарий станет менее понятным.
### Объяснение
Адаптер уже получает Playwright steps.
### Типичная ошибка
Создавать вторую структуру выполнения.
### Связь с Automation QA
Бизнес-шаги остаются в `test.step()`.

## 3. Labels и links
### Ответ
Например, owner `payments-qa`, feature `Task diagnostics`, link `CASE-230` на синтетический домен `.test`.
### Объяснение
Metadata остаётся стабильной между запусками.
### Типичная ошибка
Использовать runtime token как label.
### Связь с Automation QA
Фильтры и ownership остаются безопасными.

## 4. Attachment
### Ответ
Передайте строку JSON и `application/json` через Allure attachment API после маскирования.
### Объяснение
Адаптер связывает доказательство с текущим результатом.
### Типичная ошибка
Передать полный ответ с credentials.
### Связь с Automation QA
Отчёт содержит минимально достаточные данные.

## 5. Automation QA-задача
### Ответ
History показывает статусы и длительность прошлых запусков одной идентичности теста, но не причинную связь.
### Объяснение
Повторяемость сигнала требует отдельного расследования.
### Типичная ошибка
Назвать тест flaky по одной записи history.
### Связь с Automation QA
Глава 232 отдельно изучит причины нестабильности.

## 6. Мини-проект: результаты Allure
### Ответ
Добавьте reporter `allure-playwright`, выделенный для модуля `resultsDir`, затем owner, feature, link и безопасное вложение в тесте; custom reporter не нужен.
### Объяснение
Адаптер использует существующий результат Playwright.
### Типичная ошибка
Смешать создание HTML-отчёта с выполнением тестов.
### Связь с Automation QA
Диагностика доступна в стандартной модели Allure.
