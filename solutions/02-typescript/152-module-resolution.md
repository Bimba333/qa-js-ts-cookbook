# Решения: Module Resolution

## Концептуальные вопросы

### Ответ

Спецификатор модуля — это строка в import. Относительный импорт начинается с `./` или `../`. Нерелятивный импорт ищется по правилам проекта и не устанавливается автоматически.

### Объяснение

TypeScript должен сопоставить строку импорта с файлом или декларацией.

### Типичная ошибка

Думать, что TypeScript скачивает отсутствующие пакеты.

### Связь с Automation QA

Предсказуемые импорты помогают держать helper-функции и модели понятными.

## Чтение кода

### Ответ

TypeScript будет искать `format-title.js` рядом с текущим файлом.

### Объяснение

`./format-title.js` — относительный импорт.

### Типичная ошибка

Убирать `./` и случайно превращать импорт в non-relative.

### Связь с Automation QA

Файлы одной feature-папки удобно связывать relative imports.

## Предскажите результат проверки

### Ответ

TypeScript покажет ошибку `Cannot find module`.

### Объяснение

Строка импорта не указывает на существующий файл или декларацию.

### Типичная ошибка

Исправлять типы, когда проблема на самом деле в пути.

### Связь с Automation QA

Такие ошибки часто появляются после переименования helper-файлов.

## Анализ типа

### Ответ

`.d.ts` может описать API для TypeScript, но среда выполнения JavaScript все равно должна найти реальный модуль.

### Объяснение

Декларация не является реализацией.

### Типичная ошибка

Считать найденные типы гарантией, что код запустится.

### Связь с Automation QA

Legacy helper может иметь декларацию, но сам JavaScript-файл все равно должен существовать.

## Задание на отладку

### Ответ

```ts
import { buildReportName } from "./report-name.js";
```

### Объяснение

Если файл лежит рядом, нужен relative import.

### Типичная ошибка

Писать имя файла как package import.

### Связь с Automation QA

Относительные импорты делают локальные зависимости явными.

## Задание Automation QA

### Ответ

Если `report-file.ts` и `report-name.ts` лежат в одной папке, `report-file.ts` должен импортировать helper-функцию так:

```ts
import { buildReportName } from "./report-name.js";
```

### Объяснение

Так TypeScript ищет файл рядом с текущим модулем.

### Типичная ошибка

Использовать alias без настройки runtime-поддержки.

### Связь с Automation QA

Так проще переносить маленькие utility-папки между проектами.

## Мини-проект

### Ответ

```ts
// format-title.ts
export function formatTitle(title: string): string {
  return title.trim().toLowerCase();
}
```

```ts
// report-file.ts
import { formatTitle } from "./format-title.js";

export function buildReportFile(title: string): string {
  return `${formatTitle(title)}.json`;
}
```

```ts
// main.ts
import { buildReportFile } from "./report-file.js";

console.log(buildReportFile("Daily Report"));
```

### Объяснение

Каждый import указывает на соседний файл через относительный путь.

### Типичная ошибка

Использовать путь, который не соответствует расположению файла.

### Связь с Automation QA

Так можно собрать цепочку helper-функций отчета без глобальных зависимостей.
