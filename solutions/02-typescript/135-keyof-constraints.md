# Решения: keyof Constraints

## Концептуальные вопросы

### Ответ

`keyof T` получает union ключей типа `T`. `K extends keyof T` ограничивает ключ существующими ключами объекта. `T[K]` возвращает тип значения по выбранному ключу.

### Объяснение

Это связь между объектом, ключом и результатом доступа.

### Типичная ошибка

Использовать `string`, когда нужен конкретный ключ объекта.

### Связь с Automation QA

Вспомогательные функции конфигурации становятся безопаснее.

## Чтение кода

### Ответ

`Key` зависит от `ObjectType` и может быть только ключом этого объекта.

### Объяснение

Результат `ObjectType[Key]` соответствует конкретному ключу.

### Типичная ошибка

Считать `keyof` проверкой во время выполнения.

### Связь с Automation QA

Так можно безопасно читать настройки окружения.

## Предскажите результат проверки

### Ответ

TypeScript покажет ошибку, потому что `"timeout"` не является ключом `{ retries: number }`.

### Объяснение

Допустимый ключ только `"retries"`.

### Типичная ошибка

Ожидать, что TypeScript проверит это только во время выполнения.

### Связь с Automation QA

Опечатки в config keys ловятся до запуска.

## Анализ типа

### Ответ

`key: string` разрешает любую строку, включая несуществующие ключи.

### Объяснение

Тип результата становится небезопасным, потому что связь с объектом потеряна.

### Типичная ошибка

Не связывать ключ с конкретным типом объекта.

### Связь с Automation QA

Это частая ошибка во вспомогательных функциях для конфигурации.

## Задание на отладку

### Ответ

```ts
function readSetting<Settings, Key extends keyof Settings>(
  settings: Settings,
  key: Key,
): Settings[Key] {
  return settings[key];
}
```

### Объяснение

Ключ ограничен ключами `Settings`.

### Типичная ошибка

Возвращать `unknown` без необходимости.

### Связь с Automation QA

Helper сохраняет точный тип настройки.

## Задание Automation QA

### Ответ

```ts
function readEnvironmentSetting<Environment, Key extends keyof Environment>(
  environment: Environment,
  key: Key,
): Environment[Key] {
  return environment[key];
}
```

### Объяснение

Ключ нельзя выбрать вне формы объекта окружения.

### Типичная ошибка

Разрешить любой `string`.

### Связь с Automation QA

Так снижается риск опечаток в environment config.

## Мини-проект

### Ответ

```ts
function selectField<Data, Key extends keyof Data>(data: Data, key: Key): Data[Key] {
  return data[key];
}
```

### Объяснение

Тип результата зависит от выбранного ключа.

### Типичная ошибка

Использовать один общий тип результата для всех ключей.

### Связь с Automation QA

Это удобно для выборки полей из test data.
