# Решения: Enum

## Концептуальные вопросы

### 1. Чем enum отличается от литеральных типов?

Ответ: обычный enum существует во время выполнения, а литеральные типы — только на этапе проверки.

Объяснение: enum компилируется в JavaScript-объект.

Типичная ошибка: считать enum только типом.

Связь с Automation QA: иногда нужен общий объект со статусами во время выполнения.

### 2. Почему обычный enum существует во время выполнения?

Ответ: TypeScript генерирует JavaScript-код для enum.

Объяснение: значения enum можно читать во время выполнения.

Типичная ошибка: ожидать, что enum исчезнет как interface.

Связь с Automation QA: enum можно использовать в логике отчета во время выполнения.

### 3. Когда строковый enum понятнее числового enum?

Ответ: когда значение должно быть читаемым в логах или отчетах.

Объяснение: строка `'failed'` понятнее числа `1`.

Типичная ошибка: использовать numeric enum для пользовательских статусов.

Связь с Automation QA: отчетные статусы лучше хранить строками.

### 4. Почему enum не стоит использовать для любого набора строк?

Ответ: иногда литеральные типы проще и не создают объект во время выполнения.

Объяснение: enum нужен осознанно, когда его свойства полезны.

Типичная ошибка: заменять enum все строковые union.

Связь с Automation QA: маленький локальный набор статусов часто проще описать union.

### 5. Где enum может быть полезен в QA-коде?

Ответ: в общих статусах, режимах запуска и типах отчетов.

Объяснение: enum дает именованный набор значений.

Типичная ошибка: смешивать enum со случайными строками.

Связь с Automation QA: режим запуска можно сделать общим для нескольких helpers.

## Задание на отладку

Ответ:

```typescript
enum RetryMode {
  Off,
  On,
}

const mode: RetryMode = RetryMode.On;
```

Объяснение: numeric enum принимает значение enum, а не строку `'On'`.

Типичная ошибка: передавать имя элемента как строку.

Связь с Automation QA: режим retries должен быть выбран из enum.

## Задание Automation QA

Ответ:

```typescript
enum RunMode {
  Smoke = 'smoke',
  Regression = 'regression',
}
```

Объяснение: string enum хранит читаемые значения.

Типичная ошибка: оставить enum без явных строковых значений.

Связь с Automation QA: режим запуска попадет в отчет понятным текстом.

## Мини-проект

Ответ:

```typescript
enum RunMode {
  Smoke = 'smoke',
  Regression = 'regression',
}

function printRunMode(mode: RunMode): void {
  console.log(mode);
}

printRunMode(RunMode.Smoke);
```

Объяснение: функция принимает только `RunMode`.

Типичная ошибка: вызвать `printRunMode('smoke')`.

Связь с Automation QA: helper получает режим из общего набора.
