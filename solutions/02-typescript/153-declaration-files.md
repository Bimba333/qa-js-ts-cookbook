# Решения: Declaration Files

## Концептуальные вопросы

### Ответ

`.d.ts` файл описывает типы существующего JavaScript API. `declare` сообщает TypeScript, что значение существует где-то еще, но не создает его.

### Объяснение

Файлы деклараций нужны компилятору и редактору, а не среде выполнения JavaScript.

### Типичная ошибка

Ожидать, что декларация создаст функцию.

### Связь с Automation QA

Legacy JavaScript helpers можно описать для TypeScript-кода.

## Чтение кода

### Ответ

Объявление сообщает, что существует функция `buildReportName(title: string): string`.

### Объяснение

Оно не содержит реализации и не создает функцию во время выполнения.

### Типичная ошибка

Вызывать объявленную функцию без реальной реализации.

### Связь с Automation QA

Так можно типизировать старый report helper.

## Предскажите результат проверки

### Ответ

TypeScript покажет ошибку: второй аргумент должен быть `boolean`, а передана строка.

### Объяснение

Декларация задает сигнатуру функции для проверки.

### Типичная ошибка

Думать, что файл деклараций проверит фактическое поведение во время выполнения.

### Связь с Automation QA

Декларации помогают ловить неправильные вызовы legacy helpers.

## Анализ типа

### Ответ

Если декларация неверная, TypeScript поверит ей и может пропустить ошибку, которая проявится во время выполнения.

### Объяснение

Декларация должна соответствовать реальному JavaScript API.

### Типичная ошибка

Писать декларации приблизительно.

### Связь с Automation QA

Неверные декларации API helpers приводят к ложному ощущению безопасности.

## Задание на отладку

### Ответ

```ts
declare function readRetryCount(): number;

const retries: number = readRetryCount();
```

### Объяснение

Декларация должна отражать фактическое значение, которое возвращается во время выполнения.

### Типичная ошибка

Подгонять переменную под неправильную декларацию.

### Связь с Automation QA

Retry count должен быть числом, если код использует его как число.

## Задание Automation QA

### Ответ

```ts
declare function createLegacyReportLine(
  title: string,
  passed: boolean,
): string;
```

### Объяснение

Декларация описывает параметры и результат JavaScript helper.

### Типичная ошибка

Использовать `string` для `passed`, хотя helper ожидает boolean.

### Связь с Automation QA

Так TypeScript проверяет вызовы старого formatter.

## Мини-проект

### Ответ

```ts
declare function getEnvironmentName(): "local" | "staging";
declare function getBaseUrl(): string;
declare function writeReportLine(line: string): void;
```

### Объяснение

Каждая декларация описывает существующую функцию времени выполнения.

### Типичная ошибка

Считать эти строки реализацией функций.

### Связь с Automation QA

Так можно описать legacy environment API.
