# Решения: typeof Type Query

## Концептуальные вопросы

### Ответ

Runtime `typeof` возвращает строку во время выполнения. `typeof` в позиции типа извлекает статический тип существующего значения. Он не валидирует внешние данные, потому что исчезает после компиляции.

### Объяснение

Type query нужен для уменьшения дублирования типов.

### Типичная ошибка

Думать, что `typeof` в позиции типа проверяет JSON во время выполнения.

### Связь с Automation QA

Конфигурационные константы можно использовать как источник типа.

## Чтение кода

### Ответ

`Config` получает форму:

```ts
{
  baseUrl: string;
  retries: number;
}
```

### Объяснение

TypeScript берет статический тип переменной `config`.

### Типичная ошибка

Ожидать literal types без `as const`.

### Связь с Automation QA

Тип конфигурации можно получить от реального объекта настроек.

## Предскажите результат проверки

### Ответ

TypeScript покажет ошибку.

### Объяснение

`const status = "passed"` получает literal type `"passed"`, поэтому `Status` тоже `"passed"`.

### Типичная ошибка

Ожидать, что `Status` станет любым `string`.

### Связь с Automation QA

Константы статусов могут сохранять точные допустимые значения.

## Анализ типа

### Ответ

`typeof` в позиции типа нужен только компилятору TypeScript.

### Объяснение

После проверки типы удаляются, а JavaScript выполняет только код времени выполнения.

### Типичная ошибка

Ожидать объект времени выполнения с информацией о типах.

### Связь с Automation QA

Типы помогают до запуска тестов, но не заменяют проверку внешних данных.

## Задание на отладку

### Ответ

```ts
const testUser = {
  id: "u-1",
  email: "qa@example.com",
};

type TestUser = typeof testUser;
```

### Объяснение

Тип строится от существующего значения.

### Типичная ошибка

Продолжать поддерживать вручную два одинаковых описания.

### Связь с Automation QA

Так удобно типизировать shared test data.

## Задание Automation QA

### Ответ

```ts
const testConfig = {
  baseUrl: "https://stage.example.com",
  retries: 2,
  report: "html",
};

type TestConfig = typeof testConfig;
```

### Объяснение

`TestConfig` повторяет статическую форму `testConfig`.

### Типичная ошибка

Считать, что тип проверит файл конфигурации во время выполнения.

### Связь с Automation QA

Тип помогает держать config helpers согласованными.

## Мини-проект

### Ответ

```ts
const testStatuses = {
  passed: "passed",
  failed: "failed",
  skipped: "skipped",
} as const;

type TestStatuses = typeof testStatuses;
```

### Объяснение

`as const` сохраняет точные literal types значений.

### Типичная ошибка

Забыть `as const` и получить слишком широкий `string`.

### Связь с Automation QA

Статусы отчета остаются синхронизированными с константой.
