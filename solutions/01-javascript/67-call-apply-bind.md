# Решения: call(), apply(), bind()

## Концептуальные вопросы

### 1. Что позволяет выбрать `call()`?

Ответ: значение `this` для немедленного вызова функции.

Почему так происходит: первый аргумент `call()` становится объектом выполнения.

Распространённая ошибка: думать, что `call()` только передает аргументы.

Связь с Automation QA: можно выполнить метод reporter с явно выбранным объектом выполнения.

### 2. Чем `apply()` отличается от `call()`?

Ответ: способом передачи аргументов.

Что происходит внутри: `call()` принимает аргументы отдельно, `apply()` принимает массив или array-like collection.

Распространённая ошибка: думать, что `apply()` делает отложенный вызов.

Связь с Automation QA: удобно передавать заранее собранный список аргументов отчета.

### 3. Почему `bind()` не вызывает функцию сразу?

Ответ: `bind()` создает новую функцию.

На что обратить внимание: эта новая функция сохранит выбранный `this` и будет вызвана позже.

Распространённая ошибка: ожидать вывод сразу после `bind()`.

Связь с Automation QA: привязанную функцию reporter можно безопасно передать в тестовый раннер.

### 4. Когда `bind()` полезнее обычного вызова?

Ответ: когда функция будет передана и вызвана позже.

Почему так происходит: обычный `object.method()` работает только в момент прямого вызова.

Распространённая ошибка: использовать отделенный метод без привязки.

Связь с Automation QA: обратный вызов для результата теста часто вызывается позже.

### 5. Как восстановить потерянный `this`?

Ответ: использовать `call()`, `apply()` или `bind()` с нужным объектом выполнения.

Что происходит внутри: `call()` и `apply()` вызывают сразу, `bind()` создает функцию на будущее.

Распространённая ошибка: исправлять поля объекта, хотя проблема в форме вызова.

Связь с Automation QA: потерянный контекст reporter восстанавливается привязкой.

## Чтение кода

Ответ: `report.call(Reporter, ...)` явно задает `this` равным `Reporter`.

Почему так происходит: первый аргумент `call()` становится объектом выполнения.

Распространённая ошибка: думать, что `report` сам помнит `Reporter`.

Связь с Automation QA: метод reporter можно вызвать корректно даже после отделения.

## Предскажите результат выполнения

Ответ:

```text
[api] request started
```

Что происходит внутри: `bind(Logger)` создает функцию, где `this` зафиксирован на `Logger`.

Распространённая ошибка: ожидать, что `bind()` напечатает строку сам.

Связь с Automation QA: logger можно передавать без потери контекста.

## Отладка

Ответ: `bind()` только создает новую функцию, но не вызывает ее.

На что обратить внимание: чтобы напечатать отчет, нужно вызвать `boundReport(...)`.

Распространённая ошибка: считать `bind()` аналогом `call()`.

Связь с Automation QA: привязанный обратный вызов должен быть вызван тестовым раннером.

## Задание Automation QA

Ответ:

```javascript
const Reporter = {
  environment: 'staging',
  report(testName, status) {
    console.log(`${this.environment}: ${testName} -> ${status}`);
  },
};

function runTest(testName, status, reportResult) {
  reportResult(testName, status);
}

const reportResult = Reporter.report.bind(Reporter);

runTest('login smoke', 'passed', reportResult);
```

Почему так происходит: `bind()` сохраняет `Reporter` как `this`.

Распространённая ошибка: передать `Reporter.report` напрямую.

Связь с Automation QA: раннер вызывает обратный вызов позже, поэтому контекст нужно сохранить заранее.

## Мини-проект

Ответ:

```javascript
const Logger = {
  prefix: 'api',
  log(message) {
    console.log(`[${this.prefix}] ${message}`);
  },
};

const Reporter = {
  environment: 'staging',
  report(testName, status) {
    console.log(`${this.environment}: ${testName} -> ${status}`);
  },
};

function runTest(testName, status, log, report) {
  log(`start ${testName}`);
  report(testName, status);
}

runTest(
  'login smoke',
  'passed',
  Logger.log.bind(Logger),
  Reporter.report.bind(Reporter)
);
```

На что обратить внимание: оба метода передаются как привязанные функции.

Распространённая ошибка: передать методы без `bind()`.

Связь с Automation QA: раннер получает безопасные обратные вызовы.
