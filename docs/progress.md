# Прогресс

Здесь видно, что уже решено, а к чему стоит вернуться. Отмечаются только
проверяемые задачи: те, где решение прогоняется через набор проверок.

<ProgressBoard />

## Как это устроено

Задача переходит в состояние «решено», когда все её проверки прошли. Попытка,
после которой часть проверок не сошлась, сохраняется отдельно: она показывает,
где работа начата, но не доведена.

Задачи уровня стенда решаются локально — их состояние отмечается тем же
способом после успешной проверки.

## Учётная запись

Без учётной записи прогресс живёт в одном браузере. Есть два способа хранить
его вне браузера, и книга работает с обоими одинаково:

* **свой сервис книги** — поднимается локально или на вашем сервере;
* **Supabase** — готовый сервис, свой код разворачивать не нужно.

Выбор делается в панели выше и запоминается в этом браузере. Книга обращается
к хранилищу через четыре операции — регистрация, вход, чтение снимка, запись
снимка, — поэтому переход с одного варианта на другой ничего не меняет в
задачах и главах.

При каждой синхронизации сначала читается снимок из учётной записи, затем он
объединяется с локальным, и только потом результат отправляется обратно.
Порядок именно такой: иначе снимок, отправленный со старого устройства, стёр
бы то, что решено на новом.
